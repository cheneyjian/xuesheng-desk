# 统一课程工作区设计

## 意图

把学升课程网页和桌面扩展功能放在同一个桌面窗口中，让用户能边看课程边用录音、时间戳笔记和导出工具处理课程内容。

## 第一阶段目标

- 单个窗口内并排显示课程网页和本地功能面板。
- 课程网页保持独立、不可信的远程内容；本地面板保留受限 preload 和 IPC。
- 用户正在录音时，可在课程网页选中文字，通过右键菜单把它记为当前时间戳笔记。
- 保留现有手动笔记、录音列表、转写和导出能力。
- 录音只采集学升桌面版内课程网站的声音，其他应用声音不进入录音。
- 新录音保存为 MP3 通用格式；保留既有 WebM 录音的读取与导出。
- 窗口尺寸变化时，网页与面板布局随之调整。

## 不在本阶段

- 不读取、抓取或总结网页未选中的正文。
- 不给远程网页增加 Node、preload 或通用 IPC 能力。
- 不增加其他 AI、摘要、翻译或自动化面板。
- 不改变资料库路径和既有文字导出格式。

## 交互

- 应用启动后打开一个桌面工作区：课程网页在左，录音与笔记面板在右。
- 用户开始内录后，在课程网页选中一段文字并右键，选择“记为当前时间戳笔记”。
- 该操作将选中文字作为一条普通笔记，时间取面板收到操作时的录音时间；录音未进行或没有选中文字时，菜单项不可用。
- 现有面板里的手动笔记仍按回车或“记下”保存。
- 关闭工作区时沿用现有正在录音提示。

## 实现决策

- 使用 Electron `WebContentsView` 在同一个 `BrowserWindow` 中承载远程网页和本地面板。远程页使用原有持久化 partition、导航白名单和权限拒绝规则；面板继续加载本地 HTML 和 preload。
- 网页到面板的唯一新增通道由主进程控制：主进程接收 Electron 的上下文菜单选区，再向本地面板发送选中文字。远程页面本身不能调用 IPC。
- 在面板渲染进程记录当前录音起始时间，收到选中文字时通过既有、经校验的 `addNote` IPC 保存。
- 第一阶段固定使用 420 px 面板宽度，主窗口默认 1360×900，并设置适合两栏工作的最小尺寸。窄窗口仍允许缩小网页区，不隐藏面板。
- 本地面板只发起录音控制 IPC；主进程用 `screencapturekit-audio-capture` 将 ScreenCaptureKit 目标固定为学升应用自身 PID，再把单声道 PCM 送入 `@audio/encode-mp3` 流式编码。没有系统混音回退；目标或权限不明确时停止。
- 课程网页只能停留在 HTTPS 白名单内，工作区只承载这一个课程网页；因此按应用筛出的声音就是该课程页面在本应用中播放的声音。ScreenCaptureKit 需要 macOS 13+ 及系统采集权限。

## VMark 参考

- 借鉴 VMark 将当前选区作为明确上下文的做法：选区随当前文档状态维护，切换/隐藏编辑器时清空旧选区。学升没有多个编辑器 tab，因此主进程直接从触发右键菜单的网页 `WebContents` 获取本次选区，不复用全局“最近选区”。
- 借鉴 VMark sidebar 的显式视图模式，为后续增加独立工具面板留出清楚入口；本阶段只承载已有录音、笔记和录音库功能，不预建通用插件系统。
- VMark 的通用 `CommandBus` 服务多个菜单、快捷键、面板和自动化入口。学升当前只有一个网页选区动作，沿用一个窄事件与现有 `addNote` 业务入口即可；出现第二类真实调用入口后再考虑统一命令层。
- 参考源代码：`vmark/src/stores/documentStore/document.ts`、`vmark/src/components/Editor/TiptapEditor.tsx`、`vmark/src/components/Sidebar/Sidebar.tsx`、`vmark/src/services/commands/CommandBus.ts`。只借鉴行为边界，不移植 VMark 的 React/Tauri 技术栈。

## 验收

- 启动后只有一个应用工作区窗口，左侧是课程网页，右侧是现有功能面板。
- 窗口调整大小时两栏边界正确更新。
- 录音中对网页选中文字右键，可把它保存为带当前时间戳的笔记；列表刷新和 Markdown 导出能看到该笔记。
- 未录音或未选中文字时，不会生成空笔记。
- 面板录音、停止、历史列表和导出入口仍可见。
- 浏览器和 QQ 音乐播放声音时录音内容仍只来自学升桌面版；新录音文件为 MP3，常见播放器可打开。
- 网页仍受 HTTPS 域名白名单约束，且网页上下文没有 preload/Node/IPC 能力。

## 明确限制

自动记录只处理用户明确选中的文字，不分析或自动读取网页全文。应用音频采集仍需打包应用及 macOS 权限；未获授权时录音会失败，不会改录全系统声音。
